# PoC plan

## Decisions (2026-10-25)

- 主役は「この先どうなるか」の統計的予測。無降雨仮定の単純計算は表示の主役にせず、検証の基準として残す。
- 予測の答え合わせを記録し、モデル改善に使う。
- 出来事（取水制限など）を時系列に重ねる。AI による抽出（例: OpenAI Decisions API）は候補とし、人の確認を前提にする。
- 平時も常時稼働する。
- 通知と他水系は後回し。まず福岡市で PoC。
- Python + 静的サイト、GitHub Actions cron、private リポジトリ。

## Today

1. **Fetch**: 市テキスト版、浄水日報（平日）、気象庁 1か月予報・週間予報・アメダス降水量を取得し、`data/raw/` に取得時刻つきで保存する。
2. **Normalize**: 9ダム＋合計の貯水率・貯水量、日降水量、予報確率を日次の表（CSV）にする。
3. **Schedule**: GitHub Actions cron で毎日取得し、データをコミットする。
4. **Baseline**: 無降雨仮定の基準予測（直近の減少ペースの外挿）を毎日記録する。
5. **Model v0**: 気象庁の降水3階級確率をシナリオの重みにした確率つき見通し（例: N日後に閾値を下回る確率）。
6. **Verify**: 発行済み予測と実績の突き合わせ（誤差、確率予報のスコア）。
7. **Site**: 推移・見通し・出来事・答え合わせを1ページの静的 HTML に生成する。

学習用の過去データが薄いため、v0 は単純なモデルでよい。改善は蓄積と検証の結果を見て行う。
